# Лабораторна робота №10. Файлове введення-виведення та збереження стану за допомогою менеджерів контексту

**Виконала:** СТУДЕНТКА ГРУПИ ЕІ-24-1 МУНТЯН М.О.  
**Варіант:** 20

## Мета роботи

Опанування практичних навичок файлового введення-виведення мовою Python, використання менеджерів контексту `with`, обробки CSV-файлів, перевірки бінарних сигнатур та серіалізації результатів у формат JSON.

## Завдання 1. Обробка даних спектроаналізатора

**Вхідний файл:** `spectrum.csv`  
**Вихідний файл:** `cleaned_spectrum.csv`

**Реалізовані операції:**
- Зчитування даних за допомогою `csv.DictReader`.
- Фільтрація сигналів за критерієм потужності понад −40 дБм.
- Визначення центральної частоти відібраного діапазону.
- Збереження результатів через `csv.DictWriter`.

## Завдання 2. Бінарний аудит файлу

**Файл:** `firmware_sample.bin`

**Реалізовані операції:**
- Відкриття бінарного файлу в режимі `rb`.
- Перевірка чотирибайтової сигнатури `0x53504543` (`SPEC`).
- Зчитування версії образу.
- Використання методів `seek()` і `tell()`.
- Визначення загального розміру файлу та корисних даних.
